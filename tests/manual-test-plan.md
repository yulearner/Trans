# 手动测试清单（MVP 0.1.0）

## A. 安装与权限
- [ ] Chrome `chrome://extensions/` 开发者模式加载目录成功。
- [ ] Edge `edge://extensions/` 开发者模式加载目录成功。
- [ ] 安装时不请求所有网站权限。
- [ ] 设置中授权 API 域名时出现浏览器权限提示；拒绝授权时有清楚错误提示。

## B. 设置与 API
- [ ] 空 API Key 时翻译会提示先配置。
- [ ] Base URL 无效时保存失败并显示错误。
- [ ] 保存后重新打开设置，字段值仍存在。
- [ ] 正确配置后 API 测试返回译文。
- [ ] 错误 Key、错误模型、错误 URL 分别显示可理解的错误。
- [ ] 确认 DevTools / Console 不打印 API Key 或完整 Authorization 请求头。

## C. 网页翻译
- [ ] 在普通英文文章页点击“翻译当前网页”，正文段落下方显示译文。
- [ ] 原文仍保留，译文没有执行或渲染 HTML。
- [ ] 再次点击不会重复插入相同译文节点。
- [ ] “显示 / 隐藏译文”能切换译文可见状态。
- [ ] 无可识别段落时显示友好提示。
- [ ] 在 `chrome://`、扩展商店页等不支持页面中提示不能使用。

## D. 选中与悬停
- [ ] 选中一段文本，浮层出现并显示译文。
- [ ] 选中超过限制长度的文本时不会发送请求。
- [ ] 鼠标移动到正文段落出现“译”按钮，点击后在段落下显示译文。
- [ ] 关闭浮层按钮与 Escape 键能关闭浮层。

## E. 隐私与鲁棒性
- [ ] 不触发翻译时，不应向模型 API 发请求。
- [ ] 翻译失败时显示错误，不破坏原文内容。
- [ ] 页面动态变化后重新翻译不会导致明显重复插入。
- [ ] 使用前确认发送到模型服务的网页文本不含敏感信息。
