# 手动测试清单（MVP 0.2.0，双引擎）

## A. 安装与权限
- [ ] Chrome `chrome://extensions/` 开发者模式加载目录成功。
- [ ] Edge `edge://extensions/` 开发者模式加载目录成功。
- [ ] 安装时不请求所有网站权限。
- [ ] 设置中授权 API 域名时出现浏览器权限提示；拒绝授权时有清楚错误提示。

## B. 引擎选择与设置
- [ ] 全新环境下默认引擎为 Google 免费翻译；已保存过 API Key 的老环境升级后默认仍为 AI。
- [ ] 设置页可切换引擎并保存；关闭浏览器重开后选择仍保留。
- [ ] 选择 Google 时显示“无需 API Key”，AI 配置区域被弱化/禁用但已保存的值未被删除。
- [ ] 切回 AI 后 AI 字段恢复可编辑，且仍显示之前保存的配置。
- [ ] Popup 显示当前引擎，一键切换后整页/选区/悬停翻译都使用新引擎。
- [ ] Google 模式“测试翻译”无需任何 Key 即成功；AI 模式测试沿用原流程。

## C. Google 引擎
- [ ] 英文文章页整页翻译成功，译文显示在原文下方，不执行 HTML。
- [ ] 选中文本浮层显示 Google 译文；悬停“译”按钮翻译该段成功。
- [ ] 含特殊字符（引号、&、emoji、URL）的文本翻译正常。
- [ ] 超长段落（>1200 字符）被分段翻译并拼接，不报错。
- [ ] 断网或接口不可用时显示明确错误，不伪造译文、不回退到 AI 引擎。
- [ ] Google 失败时确认没有向 AI API 发请求（AI 控制台无新调用 / Network 无请求）。

## D. AI 引擎（回归）
- [ ] 空 API Key 时翻译提示先配置。
- [ ] Base URL 无效时保存失败并显示错误；保存后重开字段仍存在。
- [ ] 正确配置后整页 / 选区 / 悬停翻译正常。
- [ ] 错误 Key、错误模型、错误 URL 分别显示可理解的错误。
- [ ] 确认 DevTools / Console 不打印 API Key 或完整 Authorization 请求头。
- [ ] Google 模式下网络面板确认没有任何请求发往用户配置的 AI 域名。

## E. 网页翻译（通用）
- [ ] 正文段落下方显示译文，原文保留，译文没有执行或渲染 HTML。
- [ ] 再次点击不会重复插入相同译文节点；引擎切换后也不会重复插入。
- [ ] “显示 / 隐藏译文”能切换译文可见状态。
- [ ] 无可识别段落时显示友好提示；`chrome://` 等不支持页面提示不能使用。

## F. 选中与悬停
- [ ] 选中一段文本，浮层出现并显示译文。
- [ ] 选中超过限制长度的文本时不会发送请求。
- [ ] 鼠标移动到正文段落出现“译”按钮，点击后在段落下显示译文。
- [ ] 关闭浮层按钮与 Escape 键能关闭浮层。
- [ ] 选中翻译后，浮层 × 旁有“📌 固定”按钮；点击后浮层标记“（已固定）”。
- [ ] 固定后点击页面其他位置或按 Esc：浮层自动隐藏，但在原选区文本后面出现“文A”小方框。
- [ ] 点击“文A”小方框：浮层重新展开并显示之前缓存的译文（不显示“正在翻译…”、不发起请求），小方框隐藏。
- [ ] 多个固定浮层可共存：各自在原文旁保留独立的“文A”小方框，互不影响。
- [ ] 再次点击 📍 取消固定：小方框被移除，浮层恢复普通行为（点击外部直接消失，不留小方框）。
- [ ] × 关闭固定中的浮层时，浮层与小方框一起被彻底移除。
- [ ] 再次选中相同文本时直接显示之前的译文，不发起请求（可在 DevTools Network 确认）。
- [ ] 刷新页面后缓存与小方框失效，相同文本会重新翻译（预期行为，不持久化）。

## G. 隐私与鲁棒性
- [ ] 不触发翻译时，不向 Google 或模型 API 发请求。
- [ ] 翻译失败时显示错误，不破坏原文内容。
- [ ] 页面动态变化后重新翻译不会导致明显重复插入。
- [ ] 使用前确认发送到 Google / 模型服务的网页文本不含敏感信息。
