安全提示

  • Google 模式下，待翻译文本会发送到 Google 的服务端；该接口为非官方网页接口，可能变化或限流。
  • Google 模式不会发送你的 AI API Key；AI 模式不会把文本发送到 Google。
  • 只填写你信任的 API 服务商的 HTTPS 地址。网页正文会发送给你配置的模型服务进行翻译，请勿翻译包含密码、令牌或其他敏感信息的页面。
  • 扩展只在你点击按钮或选择文本时发起翻译，不会自动上传整个浏览历史。
  • 本版本尚未进行安全审计，不建议用于高度敏感的数据。
