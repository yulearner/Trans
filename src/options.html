安全提示

  • 只填写你信任的 API 服务商的 HTTPS 地址。
  • 网页正文会发送给你配置的模型服务进行翻译，请勿翻译包含密码、令牌或其他敏感信息的页面。
  • 扩展只在你点击按钮或选择文本时发起翻译，不会自动上传整个浏览历史。
  • 本版本尚未进行安全审计，不建议用于高度敏感的数据。
